How it chooses

How Mint picks a way to do it

  1. In the background: web search and page reading, file tools, the browser's own scripting, AppleScript. Nothing moves on screen.
  2. In the app, by name: the app comes to the front; Mint uses its menu bar, scrolls to things, and clicks controls by their names (from the accessibility tree).
  3. With your pointer, last: only when you say “this” or “here”, or for things nothing else can see (canvases, games), from a screenshot.

Mint is told never to say “I can't” about something on the Mac before trying these.

Clicking, typing and reading

Mint reads every control in the window, picks the one you meant, presses it like a person, and checks that something changed.

  • type “see you at six”
  • put it in the search box
  • read this page
  • what does the email say?
  • summarise this
  • look at my screen
  • what's under my mouse?
  • click this
  • press command shift T

You sayToolHow
“click Sign in”ui_actExact label first, then Jev chooses from the real list, then a vision model on a numbered screenshot. A real mouse press; the window is compared before and after.
“type …”type_textInto the focused box, or the box you name. With “and send”, it presses the chat's Send and checks it went.
“read this page”read_windowAll the text, including what is scrolled out of view

“what's under my mouse?”, “click this”pointerThe control under your pointer; clicks right there

Typing into a password field is refused: you type passwords. Send, Delete-type buttons need you to have asked.

ToolNotes
find_filesSpotlight, by name and content, newest first. With no query: recent items on Desktop, Documents, Downloads. Kinds: pdf, image, doc, sheet, slides, code, video, audio, folder, app
read_fileText, code, Markdown, CSV, JSON, PDF, Word, RTF, HTML; long files in parts
write_filecreate, append, replace (the text must occur once), overwrite (the old version is backed up first). A bare name goes to ~/Documents/Mint
file_actionopen, reveal, info, move, copy, rename, make_folder, trash. Never overwrites an existing file
Off limits: ~/.ssh, ~/.aws, keychains, cookies, Mail and Messages data, browser profiles, .env and credential files. “Delete” means the Trash, only when you asked. Text that looks like a password, key or card number is never written.

The browser

Full control of Chrome, Safari, Brave, Arc and Edge, including pages you are logged in to.

  • what tabs do I have open?

  • open github.com in a new tab
  • go back
  • reload
  • is there a pricing section?
  • click Learn more
  • put my name in the Full name field
  • choose Blue in the colour list
  • scroll to the bottom
  • close the YouTube tab
  • put YouTube and anime in a group called Entertainment
  • open the KeepWatching extension
  • always open YouTube in Brave
  • which browser do you use for what?

Which browser it uses

  1. A browser you name: “in Brave”, “on this Chrome only”.
  2. Your browser rules: ones you set (“always use Brave for entertainment”) and remembered preferences. Topics cover their sites: entertainment is YouTube, Netflix, Twitch, Spotify, anime sites…
  3. The one Gemini asked for; then the one in front; then the one Mint last used; then the Mac's default.

A tab already showing the page is reused; a browser that isn't running is started first.

Page actions are fastest with View ▸ Developer ▸ Allow JavaScript from Apple Events turned on in Chrome or Brave (Safari: Develop menu). Mint never turns it on itself; without it everything except raw JavaScript still works through Accessibility.
Password and card fields are never filled. Send, Submit, Post, Buy, Pay, Delete and closing tabs need you to have asked. Page scripts cannot read cookies or storage, send data out, or submit forms.

Menus, scrolling and AppleScript

  • in Finder go to Applications
  • export this as PDF
  • what's in the View menu?
  • what's the shortcut for…?
  • scroll to Privacy & Security
  • scroll the sidebar down
  • how much free space do I have?
  • how many tracks are in my Focus playlist?

menu reads the menu bar directly (no clicking) and reports shortcuts; it notices when an item already says “Hide Path Bar”. scroll_to scrolls the right pane until the thing appears, then highlights it. run_applescript covers scriptable apps (Finder, Music, Notes, Reminders, Calendar, Mail drafts, System Events). Quit, Close, Delete, Send and Empty Trash are refused unless you asked.

Screenshots and the clipboard

Screenshots

  • take a screenshot
  • screenshot this window
  • screenshot the chart
  • take an 800x600 screenshot
  • let me pick the area
  • don't save it, just copy it

Saved where macOS saves screenshots and copied to the clipboard. A window works even when covered. Mint's own orb and chat never appear in it.

Clipboard

  • what's on my clipboard?
  • copy the path of this
  • copy this file
  • paste it
  • what did I copy before?
  • bring back the second one
  • clear the clipboard

The last 30 copies are kept in memory only, never on disk. Hidden password-manager items and anything that looks like a secret are never kept.

Doing things

Long tasks across apps

  • do all your tricks, then smile, then tell me the time
  • open ChatGPT, research honeybees with sources, give it to Codex to build a one-page site, open it on localhost and check it
  • open Notes, Calendar and Slack
  • All of it in one go. Ask for a list and Mint does it back to back without waiting for “next”, then reports once. If it stops half way, it is nudged to carry on.
  • Waiting for apps. wait_until_done watches ChatGPT (or any app) until the answer stops changing and no Stop button is left.
  • Showing what was built. preview_site serves a folder on localhost:8000, opens it, and checks the title and missing files.
  • Sending safely. A message is sent only when you asked, and never twice within two minutes.
