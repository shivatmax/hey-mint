Configuration

Every setting with its default and what it does, the files Mint keeps them in, and the environment variables for keys and models.

Where settings live

You rarely need any of this: every setting below is a switch in Settings (⌘,), and you can just ask Mint (make it pink). This page is for people who like to see everything at once.

FileWhat's in it
settings.jsonEverything on this page. Mint writes it when you change a setting, and reads it again within a couple of seconds when you edit it by hand: changes apply at once, shortcuts included. Open it from Settings ▸ Updates & Help ▸ The settings file ▸ Edit…. Only the settings you changed are stored; the rest use the defaults below.
.envYour API keys and the environment variables, one NAME=value per line, readable only by you. Settings ▸ Accounts & keys writes it for you.
custom.jsonYour accounts, Slack workspaces, aliases and routines (copy custom.example.json to start).
providers.jsonThe agents' model choices from Settings ▸ Models & agents: custom OpenAI-compatible endpoints, the Ollama address, backup models.

The downloaded app keeps these in ~/Library/Application Support/Hey Mint; an app built from source with ./install.sh keeps them in ~/Library/Application Support/Mint. Updating or reinstalling keeps them.

Keys such as shortcuts.toggle live inside an object in the file: "shortcuts": {"toggle": "cmd+j"}. Values marked empty are "" or [], which means “use the built-in choice” as described.

Shortcuts, dictation and screenshots

A shortcut is written like cmd+j or ctrl+option+space; empty means no shortcut. See Shortcuts and dictation.

SettingDefaultWhat it does
shortcuts.togglecmd+jOpens the chat, and closes it again (Esc closes it too).
shortcuts.closeemptyCloses the chat. Empty because ⌘H is Hide in every app, and a global shortcut would take it from all of them.
shortcuts.talkctrl+option+spaceWakes Mint to listen, without the wake word.
shortcuts.dictateright_optionHold it to dictate at the cursor; tap it twice for hands-free. A key combination, or one modifier on its own: right_option, right_command, right_control, right_shift or fn.
shortcuts.dictate_toggleemptyStarts and stops hands-free dictation.
shortcuts.clipboardctrl+option+vOpens the clipboard history.
shortcuts.hidectrl+option+hHides or shows Mint.
dictation_wordsemptyWords dictation should spell exactly (names, jargon), separated by commas.
screenshot_tobothWhere screenshots go: both (a file and the clipboard), clipboard or file.
shortcuts_blockedemptyApple Shortcuts Mint may not run, by name. Empty = all allowed.

The guard

SettingDefaultWhat it does
guardallWhen the guard asks first. all: before deleting, before changing or moving existing things, and before risky system commands. delete: only deleting and risky commands. off: never (risky words still need your request). Mint's own files always ask first.

Environment variables

Put these in .env (see Where settings live), one NAME=value per line. Values already set in the environment win. Restart Mint after a change.

Keys

VariableDefaultWhat it's for
GEMINI_API_KEYnot setRequired: Mint's voice and most of its work. Free at Google AI Studio.
GEMINI_API_KEY_2not setOptional second Gemini key: doubles the free limits, and each key covers for the other.
OPENAI_API_KEYnot setAgents on OpenAI models.
ANTHROPIC_API_KEYnot setAgents on Claude models.
OPENROUTER_API_KEYnot setAgents on any model OpenRouter offers.
GROQ_API_KEYnot setAgents on Groq's fast open models.
XAI_API_KEYnot setAgents on xAI's Grok.
TYPESAFE_API_KEYnot setJev, the fast chooser (which button, which skill, which memory), and the desktop tool for multi-step clicking in any app.
EXA_API_KEYnot setBetter web search for agents (DuckDuckGo otherwise).
TAVILY_API_KEYnot setBetter web search for agents, if you have no Exa key.
TELEGRAM_BOT_TOKENnot setYour own Telegram bot, for control from your phone.

Behaviour

VariableDefaultWhat it does
MINT_ALLOW_SHELLnot set1 turns on the shell tool. It is the one tool that can do arbitrary damage, so it is off unless you ask for it.
MINT_ALLOW_SEARCHnot set1 lets the voice model use Google Search grounding. Off because it is billed separately, and on a free key the session is refused.
MINT_DESKTOP_TIMEOUT75Seconds to wait for one desktop goal before giving up.
MINT_SLEEP_AFTER12Seconds of quiet before Mint stops streaming and waits for the wake word again.
MINT_WAKE_THRESHOLD0.5How sure the wake word detector must be, from 0 to 1. Higher means fewer false wakes and more missed ones.
MINT_TRANSCRIBEnot setgemini sends a video's audio to Gemini instead of transcribing it on this Mac (for videos without captions).
MINT_MEETING_KEEP_WAVnot set1 keeps the uncompressed meeting recordings too.
MINT_NO_LEARNINGnot setAny value stops Mint from writing new skills from experience.
MINT_DEBUGnot setAny value prints each internal step to the log.
