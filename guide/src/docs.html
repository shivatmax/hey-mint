Install

One download with everything inside: Python, libraries and models. Apple silicon Macs on macOS 14.2 or later.

Download it (no Terminal)

  1. Download Hey-Mint-…-arm64.dmg from the latest release, open it and drag Hey Mint onto Applications. (Opened straight from the DMG or Downloads, Hey Mint offers to move itself there: click Move to Applications.)
  2. Open Hey Mint from Applications. The first time, macOS says “Apple could not verify ‘Hey Mint’ is free of malware…”: click Done.
  3. Open System Settings ▸ Privacy & Security, scroll down to “Hey Mint” was blocked, click Open Anyway, type your Mac password and click Open Anyway again. (On macOS 14: right-click Hey Mint ▸ Open ▸ Open.)

Once per Mac, never again. New versions install themselves, without that question and keeping Mint's permissions, so there's no need to download the DMG again. Why macOS asks at all: Hey Mint is free and open source, and Apple only skips this question for developers who pay it a yearly fee.

Or one line in Terminal (macOS asks nothing)

Open Terminal (Spotlight ▸ “Terminal”), paste this and press Return:

curl -fsSL https://raw.githubusercontent.com/shivatmax/hey-mint/main/packaging/install.sh | bash

It downloads the latest Hey Mint, checks it, puts it in Applications, approves it with macOS (the same thing Open Anyway does) and opens it. It is a short script you can read first; it's also at hey-mint.pages.dev/install.sh.

Then

  1. The welcome window takes it from there: your name, what to call Mint and where it lives (in the notch or floating), then Connect: open Google AI Studio, click Create API key (free), and press Paste. Mint checks the key with Google before saving it on this Mac. The next page is optional: a Jev key for faster, surer clicking - open TypeSafe's console, create a key, press Paste (or Skip; without Jev, Gemini makes those choices).
  2. Then a voice, the permissions (each with why, and an Allow button), your shortcuts and a short tour. Change the key any time in Settings ▸ Models & agents.

Say “Hey Mint”, then ask. Your words and Mint's reply appear as captions beside the orb. Right after it answers you can follow up without the wake word for a few seconds; then it goes back to waiting for “Hey Mint”.

Only what's meant for Mint. Before Mint answers or does anything with what it heard without the wake word, it checks the words are for it and ask it something: talk with someone else, a video or call in the background, a passing phrase get no reply and no action, and don't keep it listening. A lone “hmm” or “okay” gets no answer either, unless Mint has just asked you something. “Stop”, and yes or no to the guard, always get through. Settings ▸ General ▸ Keep listening after a reply: 4 to 12 seconds, or never (always say “Hey Mint”).

If Mint ever freezes. Mint watches itself: if it stops responding, a ⚠ appears in the menu bar with Restart Mint, and after about 40 seconds it restarts by itself, writing where it got stuck to the log. ⌃⌥⌘M restarts it any time, and Settings ▸ General has Restart Mint too. No need to restart the Mac.

If the voice service is down. The caption says what's wrong in a line - no quota left, Google's side, no network, the key - and counts down to the next try, instead of going quiet. If you were waiting for an answer, Mint says so out loud.

Always the quickest voice. Mint can talk through several Gemini voice models, each with its own allowance per minute. If the one in use is slow, stalls, or nears its limit, Mint moves to the next at a quiet moment - or at once, asking it again, when you're left waiting - and comes back when the first is quick again. A model that keeps misbehaving rests longer each time, from minutes to a week. Newer models are picked up on their own.

Light to start. Each conversation starts with Mint's everyday tools only. The rarer ones - video editing, spreadsheets, translating documents, pictures, screen recording and more - are looked up the moment you ask, which adds about a second. If Mint catches itself repeating the same step with nothing changing, it stops and tries another way or asks you.

An agent saying “Done, all tests pass” isn't proof. Mint reads what really happened in Claude Code's and Codex's own logs: every test run's result from its output, the files it changed, the risky steps. Ask, and you get the evidence, not the agent's word.

Tests, read from their output. pytest, unittest, jest, vitest, mocha, node:test, go, cargo, dotnet, Maven, Gradle, PHPUnit, RSpec, Swift and more: Mint reads the summary itself (2 of 48 failed - test_total: expected 3, got -1) and when it ran. A run where no test actually ran, the output was cut with | tail, or the exit code and the output disagree reads as unclear, never as passed. Change a file after the tests pass and Mint says so: changed invoice.ts since, so the latest code isn't tested. A step that failed and then worked says fixed on try 2.

Worth a second look. Mint flags .env or key files changed, a force-push, git reset --hard, rm -rf, curl | sh, the same command failing three times, a test changed to pass while it was failing (an assertion taken out, a skip added, an expected value changed), and two agents changing the same file within minutes. These show in the notch, in the answer when you ask, and under the agent's done message on Telegram (✅ tests passed · ⚠️ not tested since the last change · 🚩 changed .env).

Send Claude back to fix failing tests (optional, off by default; needs Connect Claude Code). A request that changed no code, a project without tests, and failures that were there before it changed anything are never held up. Let agents ask Mint. Settings ▸ Appearance & Sound ▸ More options ▸ Claude mode ▸ Let agents ask Mint connects Claude Code or Codex to Mint as a read-only MCP server, so the agent itself can call check_my_work before it says “done” and gets the same evidence: Not done yet: you changed calc.py after the last test run… Run the tests again, then Looks ready once they pass. The guard: nothing deleted without your yes

Before Mint deletes, overwrites, moves or changes anything - or runs a command that could - it stops, shows you exactly what, and waits for your yes.

{{video notch-guard 700 | “Delete last year's invoices”: Mint lists the three files it would move to the Trash and waits; “yes”, and only then are they moved.}}

What it asks about: moving files to the Trash, overwriting a file that exists, moving or renaming files, merging or tidying folders, deleting notes, reminders, events, skills, memories or automations, clearing notifications or the clipboard, changing calendar events, scripts and shell commands that delete, overwrite, force-push, use sudo or change system settings, ⌘⌫, clicking a Delete or Empty Trash button, turning Wi-Fi or Bluetooth off. Opening, reading, creating new files and everyday clicks don't ask.

How you answer: the card under the notch (or by the orb) says what will happen - the files with their sizes, or the command - with Don't and Yes, do it, and a bar counting down 90 seconds. Say “yes” or “no”, type it, or click. When the request came from your phone, or you're away from the Mac, the same question comes on Telegram with ✅ Yes / ❌ No. No answer means no; “stop” means no.

Helpers and Claude Code too. Mint's helper agents ask the same way before a risky shell command or writing over one of your files. With Claude Code connected (Claude mode), a destructive command - rm, git reset --hard, push --force, sudo - makes Claude Code ask you first even where you had allowed it, and that question reaches the notch and Telegram.

Mint's own files always ask. Deleting or writing over Mint's memory, skills, settings or app, or Claude Code's and Codex's settings, asks first even when the guard is set to never - for Mint, its helpers and Claude Code alike.

Three noes and it stops. Say no three times to the same task and Mint stops trying, then asks what you'd like instead. When several background jobs ask at once, yes to all or Telegram's Allow all answers them together.

Memory

Mint remembers what you tell it and what you do together, keeps the important things in every conversation, and finds the rest by meaning when it matters.

  • remember my manager is Meera
  • my manager is now Rahul
  • who's my boss?
  • forget my old address

Three kinds of memory. About you: how you like things done (“keep replies short”, “open apps full screen”). Facts: people, work, accounts, places. Journal: what happened on a day, written as you go. What you told Mint always counts more than what it worked out by itself.

Always at hand. Every conversation starts with About you and the facts that matter most - ranked by how often they were confirmed and used, never cut off mid-line - plus the last few days. Everything else is found the moment it's needed, by words and by meaning (“that pizza place” finds the note about Luigi's on 5th), with typed and phone requests carrying what's relevant to them. Facts older than three months are marked as possibly out of date.

Kept clean. Saying the same thing twice confirms it instead of saving a copy. When a fact changes, the new one takes over and the old one is kept as history. Mint saves only lasting things - not prices, battery levels or what it clicked. Once a day it merges duplicates, retires facts nobody used in three months (still findable if you ask) and keeps the summary of what's in progress honest. Conversations are saved as they happen, so a crash or restart loses nothing. Read and edit every fact in the Skills & Memory window; forget retires a fact, and forgets it for good when you say so. How much it moves

AnimationWhat you get
Full (playful)Everything: bouncy springs, hops, sparkles, idle tricks
CalmGentle: things settle without bouncing, idle tricks are rarer and quieter (a wink or a glance), no little trips or confetti; hearts and notes fade in place instead of floating up
Minimal (fades only)Short fades instead of movement: no travel, bounce or particles; a poke gets a blink

When Reduce motion is on in macOS (System Settings ▸ Accessibility ▸ Display), Mint always behaves as Minimal, whatever this says.

The little sounds

Mint makes its own soft, short sounds - no sound files, just a few tones made on your Mac.

GroupWhen you hear it
Notch opening and closingThe notch opens or folds (also when you press Esc on it)
TasksA coding agent finishes or fails, an error card, a long job reaching 100%, a request sent from the notch, a file dropped, a tap on Retry or on an agent's chip
PlayPokes, getting dizzy, and the morning hello

Never in the way. Sounds stay quiet while you dictate, while Mint listens to you, while you're on a call (a call app has the mic, or a Google Meet with Mint is on) and while a meeting is being recorded, so a chime never lands in your microphone or a recording. Only the notch opening and closing and the morning hello play while Mint listens.

Updates

Hey Mint updates itself. When a new version is out, it downloads in the background and installs while you're away from the Mac, replacing the app in place and reopening it. No second copy, and your permissions stay.

Each update is checked before it is installed: its checksum must match the release, and it must be signed with the same certificate as the app you have. Anything else is refused. Turn it off, or check by hand, in Settings ▸ Updates & Help. The first version with updates (0.3.0) is installed by hand once; after that it's automatic.

Report a problem

Something went wrong? Choose Report a problem… in the menu bar (or Settings ▸ Updates & Help). A new GitHub issue opens in your browser with your version and macOS filled in.

The recent errors from Mint's log are copied to your clipboard, with paths, emails, keys and everything you or Mint said removed, so you can paste them in if you like. Nothing is sent until you submit the issue yourself.

Privacy and safety

🎙️Nothing leaves your Mac while Mint is asleep. The wake word and voice lock run on the Mac.
🔒Never enters passwords or card numbers, and never saves secrets in files, skills or memory.
✉️Never sends email; messages and forms go out only when you asked.
🗂️“Delete” means the Trash; files are backed up before they're changed; private folders are off limits.
✋“Stop” halts everything at once, including queued clicks and keys.
