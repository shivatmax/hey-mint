Where settings live

You rarely need any of this: every setting below is a switch in Settings (⌘,), and you can just ask Mint (make it pink). This page is for people who like to see everything at once.

FileWhat's in it
settings.jsonEverything on this page. Mint writes it when you change a setting, and reads it again within a couple of seconds when you edit it by hand: changes apply at once, shortcuts included. Open it from Settings ▸ Updates & Help ▸ The settings file ▸ Edit…. Only the settings you changed are stored; the rest use the defaults below.
.envYour API keys and the environment variables, one NAME=value per line, readable only by you. Settings ▸ Accounts & keys writes it for you.
custom.jsonYour accounts, Slack workspaces, aliases and routines (copy custom.example.json to start).
providers.jsonThe agents' model choices from Settings ▸ Models & agents: custom OpenAI-compatible endpoints, the Ollama address, backup models.

The downloaded app keeps these in ~/Library/Application Support/Hey Mint; an app built from source with ./install.sh keeps them in ~/Library/Application Support/Mint. Updating or reinstalling keeps them.

Keys such as shortcuts.toggle live inside an object in the file: "shortcuts": {"toggle": "cmd+j"}. Values marked empty are "" or [], which means “use the built-in choice” as described.

Environment variables

Put these in .env (see Where settings live), one NAME=value per line. Values already set in the environment win. Restart Mint after a change.
